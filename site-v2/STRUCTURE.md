# サイト構成

| パス | 用途 |
| --- | --- |
| `index.html` | 新サイトへの入口。旧ハッシュを対応する画面に転送 |
| `site-v2/` | 現行サイトの実装と編集データ |
| `site-v2/records/` | 作品・書籍の項目、About・Hobby・Links のデータ |
| `site-v2/articles/` | 記事と付属資料 |
| `site-v2/images/` | アイコン、プロフィール画像、アルバム写真 |
| `site-v1/` | 旧サイトと試作のアーカイブ。移行資料と過去の生成物はローカル保管 |
| `.local/originals/` | 加工前や公開を保留した写真・スクリーンショット |
| `.publish/<生成日時>/` | 静的ホスティングに渡す公開用ファイル |

編集方法は [編集ガイド](EDITING.md)、動作検査と公開方法は [公開手順](DEPLOY.md) に記載しています。
